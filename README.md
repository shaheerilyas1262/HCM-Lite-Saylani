1. Features
- Company setup aur Admin/Employee login.
- Employees ko add, edit, search aur delete karna.
- Employee check-in aur check-out.
- Late aur half-day attendance calculate karna.
- Leave apply, approve aur reject karna.
- Dashboard par attendance aur employee stats dekhna.
- Monthly salary slip aur PDF print karna.
- Smart Helper se app ke data ke mutabiq answers lena.
- Company settings aur announcements.
- Mobile aur desktop responsive design.
2. VS Code mein kaise chalayein?
1. ZIP file extract karo.
2. HCM_Lite_Saylani folder VS Code mein open karo.
3. Live Server extension install karo.
4. index.html par right-click karke Open with Live Server karo.
5. Company aur Admin account banao.
6. Employees section mein employees add karo.
3. Leave System
- Past aur future dates select kar sakte ho.
- Leave days automatically calculate honge.
- Overlapping dates aur leave balance check hoga.
- Admin leave approve ya reject kar sakta hai.
